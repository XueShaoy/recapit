## Purpose

定义长录音本地转写时对用户可见的耗时预估、持续活动状态、流式处理进度和可选文字预览，使用户能够判断任务是否正常运行并合理预期完成时间。

## ADDED Requirements

### Requirement: 转写前展示录音和执行信息
CLI SHALL 在完成媒体校验后、开始 Whisper 推理前展示录音时长、模型、设备、计算精度和预计转写耗时；预计耗时 SHALL 标明估算依据和不确定性。

#### Scenario: 有本机历史性能数据
- **WHEN** 当前机器存在与模型、设备和计算精度匹配的有效历史性能数据
- **THEN** CLI 根据录音时长和本机历史处理速度显示预计耗时范围，并标明“基于本机历史”

#### Scenario: 首次使用当前运行配置
- **WHEN** 当前机器没有与运行配置匹配的历史性能数据
- **THEN** CLI 根据录音时长和保守的首轮实时率范围显示预计耗时区间，并标明“首次估算，开始后动态校准”

#### Scenario: 模型可能需要下载
- **WHEN** CLI 无法确认所选模型已完整缓存在本机
- **THEN** CLI 明确提示首次模型下载时间不包含在转写耗时估算内

### Requirement: 转写期间持续报告进度
CLI SHALL 在模型加载和转写期间持续提供活动反馈；转写进度 SHALL 包含已处理音频位置、总时长、百分比、已生成分段数和已耗时，且百分比不得倒退。

#### Scenario: 模型正在加载
- **WHEN** Whisper 模型尚未完成加载且命令仍在运行
- **THEN** CLI 持续显示模型加载状态和已耗时，使用户能够区分运行中与无响应

#### Scenario: 收到新的识别分段
- **WHEN** Whisper 产生新的有效分段
- **THEN** CLI 使用当前已处理的最远音频位置更新进度、百分比和分段数量

#### Scenario: 长时间没有新分段
- **WHEN** 模型加载、静音区间或单个推理窗口导致一段时间没有新分段
- **THEN** CLI 仍定期更新活动状态和已耗时，不表现为静默卡死

#### Scenario: 转写完成
- **WHEN** Whisper 分段流正常消费完毕
- **THEN** CLI 将进度更新为 100%，显示本次转写总耗时，并继续执行检查点写入

### Requirement: 动态计算预计剩余时间
CLI SHALL 在获得足够的运行样本后根据实际处理速度计算预计剩余时间；样本不足时 SHALL 明确显示 ETA 尚在计算，而不得显示虚假的精确值。

#### Scenario: 样本足以估算
- **WHEN** 已处理的音频量和运行时间达到稳定性阈值
- **THEN** CLI 根据平滑后的实际实时率显示预计剩余时间，并随处理进展更新

#### Scenario: 样本尚不足
- **WHEN** 转写刚开始或有效处理样本不足
- **THEN** CLI 显示“预计剩余时间计算中”，同时继续显示百分比和已耗时

#### Scenario: 音频含有长静音
- **WHEN** 当前分段时间不能准确反映 Whisper 对静音区间的内部处理位置
- **THEN** CLI 保证进度不倒退，在分段流结束时收敛到 100%，并将 ETA 表述为估算值

### Requirement: 适配交互终端和日志环境
CLI SHALL 自动适配输出目标：在支持原位刷新的交互终端中显示单行动态进度，在非交互环境中定期输出独立状态行。

#### Scenario: 交互终端运行
- **WHEN** 标准错误输出连接到支持动态刷新的终端
- **THEN** CLI 原位更新活动指示、进度和 ETA，避免持续追加重复状态行

#### Scenario: Agent 或流水线捕获输出
- **WHEN** 输出被 Agent 命令面板、管道或日志系统捕获
- **THEN** CLI 至少每 30 秒或每增加 5 个百分点输出一行状态，以先发生者为准

#### Scenario: 转写失败
- **WHEN** 模型加载或转写过程抛出错误
- **THEN** CLI 结束动态显示、换行输出可操作的失败信息，并以非零状态退出

### Requirement: 可选显示实时识别文字
CLI SHALL 提供显式选项允许用户查看最新识别文字，默认 SHALL 不在终端输出录音正文。

#### Scenario: 使用默认隐私行为
- **WHEN** 用户未启用实时文字选项
- **THEN** CLI 只显示进度元数据，不把识别文字写入终端或捕获日志

#### Scenario: 用户启用实时文字
- **WHEN** 用户显式启用实时文字选项
- **THEN** CLI 随进度显示最新的非空识别片段，同时仍生成完整的标准转写产物

### Requirement: 本机性能历史不影响核心转写
系统 SHALL 仅保存计算耗时所需的非内容性能数据，且历史记录缺失、损坏或不可写时 MUST 继续完成正常转写。

#### Scenario: 成功完成转写
- **WHEN** 一次转写正常完成
- **THEN** 系统可记录机器、模型、设备、计算精度、音频时长和实时率，不记录音频路径或转写文字

#### Scenario: 历史文件不可用
- **WHEN** 性能历史文件不存在、格式无效或不可写
- **THEN** CLI 回退到首轮估算或仅使用本次动态 ETA，且不使转写失败
